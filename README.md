# 深岩银河-聊天翻译mod

《深岩银河》游戏内中英聊天翻译模组，直接读取聊天文字。收到的英文可译成仅本机显示的中文；输入的中文可在发送前译成英文。支持聊天记录、文本导出和界面布局调整。

**需要 Mintcat、UE4SS 框架和智谱 API 密钥。当前版本：0.2.3。**

## 使用前准备

- Windows 上的 Steam 版《深岩银河》。
- [Mintcat](https://github.com/iris-cat-dev/mintcat)，并在其中开启 UE4SS 框架。
- [智谱开放平台](https://open.bigmodel.cn/console)账号及有效 API 密钥。默认模型为 `glm-4-flash-250414`，需有该模型的调用权限。

Mod Hub 可选：安装后按 H 打开，在左侧“Chat Translator · 聊天翻译”入口选择 **Settings**，页面内容为中文；没有 Mod Hub 时使用 F9。

## 安装

1. 在 [Releases](https://github.com/muzhouyi/drg-chat-translator/releases) 下载 `drg-chat-translator-0.2.3.zip` 并解压。
2. 退出游戏，在 Mintcat 添加本地模组，选择解压得到的 `DRGChatTranslator-0.2.3-Mintcat.zip`。停用旧版本，开启 UE4SS 框架并保存更改。
3. 双击 `配置翻译.cmd`，填写游戏根目录和智谱 API 密钥，点击“保存配置”。游戏目录可在 Steam 中右键《深岩银河》→ **管理 → 浏览本地文件** 找到。
4. 启动或重启游戏，进入空间站，按 F7 测试接口。错误详情可在配置工具的“查看运行状态”中查看。

安装包已包含 Mod Hub 适配组件，由 Mintcat 合并安装。不要将 `DRGChatTranslatorHub_P.pak` 单独复制到游戏的 `Paks` 目录。若此前安装过早期调试版并手动放入该文件，请先将独立文件移出，再通过 Mintcat 安装新版。

## 操作

| 按键 | 功能 |
| --- | --- |
| F6 | 重新加载配置与界面布局，随后重新打开 F9 |
| F7 | 测试智谱 API |
| F8 | 将聊天草稿译成英文；F9 打开时作用于面板输入框 |
| F9 | 打开或关闭聊天面板，查看记录、输入聊天、手动翻译和导出 |

使用 F8 前先完成中文输入法选字。翻译只修改草稿，检查结果后自行按回车或点击“发送”。翻译失败或翻译期间修改输入时，会保留原文或新的输入。

F9 面板底部可直接输入并发送普通聊天，也可先点击“翻译成英文”再发送。再次按 F9 或点击右上角关闭按钮退出面板，恢复游戏操作。

F9 和 Mod Hub 提供总开关及“自动英→中”开关。自动翻译处理开启后的新英文及中英混合聊天；关闭自动翻译后，可点击消息旁的“翻译／重新翻译”按需翻译。关闭总开关会暂停翻译，仍保留聊天记录和普通发送功能。

## 调整界面与导出

- **拖动面板：** 按住 F9 面板顶部标题栏拖动，松开后保存位置。
- **调整布局：** 双击 `调整界面.cmd`，填写游戏目录，调整面板宽高、位置、字号、列宽比例、行距和每页条数。保存后在游戏按 F6，再打开 F9。工具预览为示意，实际字体和换行以游戏为准。
- **导出聊天：** 点击 F9 的“导出聊天”，将全部已保存聊天及已有译文导出为 UTF-8 文本。成功后可在配置工具的运行状态中查看文件路径。

## 记录与 API 使用

F9 查看记录、翻页、拖动、清空和导出聊天不会调用 API。已有译文优先从本机缓存读取；“清空聊天”保留译文缓存。最多保存 1000 条聊天和 2000 条译文缓存。

执行翻译时，聊天文字会提交给智谱。密钥、聊天记录和缓存保存在游戏目录的 `FSD\Saved\SaveGames\Mods\DRGChatTranslator` 下。

该目录中的 `ui-layout.json` 保存布局；`chat-export-日期时间.txt` 为导出的聊天文件。界面调整工具只读写布局，不读取密钥或聊天记录。

## 验证范围

0.2.3 已通过 62 项本地检查，包含模拟测试与适配组件读回检查。F9 输入发送、拖动、导出，以及关闭面板后恢复角色控制已获得实际游戏复测确认。适配环境为 UE4SSL 0.31.0、Mod Hub 1.2.5。

此前出现过任务结算断线与长时间运行崩溃。当前版本已加入相关修正，但这些问题是否完全消除尚未确认，不能将功能复测结果视为长期稳定性验证。

开发者可使用 Node.js 执行 `npm test`。玩家使用安装包无需安装 Node.js。
